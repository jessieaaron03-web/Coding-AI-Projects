# Security policy

## Reporting a vulnerability

Please do not publish secrets, personal data, or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository; otherwise contact the maintainer privately through their GitHub profile.

## Safe use

- Never commit API keys, passwords, access tokens, or private datasets.
- Keep local configuration and secret files out of version control.
- Treat prompts, datasets, model outputs, and generated reports as potentially sensitive.
- The API is a development/demo service and has no authentication. Keep it on localhost unless you have added suitable access controls.
- Only send data to model endpoints you trust.
