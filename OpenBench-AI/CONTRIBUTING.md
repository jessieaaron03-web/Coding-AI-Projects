# Contributing

Thanks for your interest in OpenBench AI!

1. Open an issue describing the bug, proposal, or evaluation question.
2. Add or update tests for changed behavior.
3. Run `pytest` and `ruff check .`.
4. Describe the test environment and limitations in your pull request.

Never commit API keys, access tokens, private datasets, or personal data. Benchmark results must be reproducible and must not be fabricated.
